Terza media

Regola 64

Il periodo ipotetico di tipo zero e di primo tipo

Le parole

  • if [if]
  • I’ll [àil]
  • would [uud]

Le frasi

  • If it rains, I’ll stay at home.
    Se piove, resto a casa.
  • If you heat ice, it melts.
    Se scaldi il ghiaccio, si scioglie.
  • I’ll call you if I have time.
    Ti chiamo se ho tempo.
  • If you study, you’ll pass the exam.
    Se studi, passerai l’esame.

L’audio legge prima le parole, con una pausa per ripetere, e poi le frasi, due volte ciascuna.
